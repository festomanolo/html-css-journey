# HTML & CSS Journey

My very first steps into web development (June 2022 – September 2023). These are the raw practice pages I wrote while learning HTML, CSS and a little JavaScript, kept as-is to show where I started.

## What's inside

| Page | What I was practicing |
|------|-----------------------|
| `ExpertismHTML.html` | First styled page: headings, gradients, `<hr>` — an essay on democracy |
| `Day3.html` | CSS selectors: classes, ids, text-shadow |
| `tashaworkday4.html` | External stylesheet, lists, classes vs ids |
| `RoughWork.html`, `ContactForm.html` | Tables and framesets |
| `form.HTML` | Forms, radio buttons, audio and `<progress>` |
| `JAVASCRIPT.HTML`, `catalog.js` | First JavaScript: `onclick`, `Date()`, generating cards in a loop |
| `Homework1HTML.html` | A long-form page on global warming with images and video |
| `portifolio.html`, `portfolio.css` | My first personal portfolio page |
| `ANO.HTML` | `window.alert()` prank page |
| `Beginning.html` | Quantum physics page with a background image |
| `DAY2HTML.html`, `hello.html`, `hello_world.html`, `EXPRESS.HTML`, `hello-nolo.html`, `BACKGROUND.HTML` | Lists, links, media and background experiments |

```
.
├── *.html / *.HTML      practice pages
├── style.css, portfolio.css, catalog.js
├── tashaworkday4_files/ second page + styles for the day-4 lesson
├── assets/images/       images used by the pages
├── assets/video/        video for the global warming page
└── screenshots/         screenshots taken while working
```

## Run it

No build step. Open any `.html` file in a browser.

## Notes

These are learning files, so they still have beginner mistakes: unclosed tags, inline styles everywhere, and some links that point to files on my old Windows machine (`C:\Users\...`). I left them that way on purpose so the repo shows where I started.
